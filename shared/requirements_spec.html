Key Transformation Rules
  • Education sorted by Display Order ascending
  • Side Projects sorted by Display Order Sequence ascending
  • Companies sorted by most recent start date first; current companies first
  • Roles within company sorted by most recent first
  • Majors: join Education-Major → Major to get Major Name — never store M_ID
  • Cert skill: join Skills to get Skill Name — never store S_ID
  • Radar scores: sum task counts for all skills in each category where Radar Chart = Y; merge "AI / ML" into "AI / ML / Coding"
  • Treemap top 5: technical categories only (excludes Team/Project Management), sorted by task count descending
  • Location priority: Bangkok first, then others
  • Task-Skills deduplication: when building task.skills array, deduplicate by S_ID — a skill must appear at most once per task even if Task-Skills sheet has duplicate rows for the same T_ID + S_ID combination
  • Total experience = sum of individual role tenures (NOT career date span)
  • Reloc pill hidden if person.country === "Australia"
  • QR code URL: https://praphani.github.io/01-InteractiveCV/
04 HTML Output — Critical Rules
THE MOST IMPORTANT RULE:

build.py must embed ALL data as an inline JavaScript object in the generated HTML. Do NOT use fetch() or XMLHttpRequest to load cv_data.json at runtime. fetch() fails silently on local file:// URLs (CORS), leaving the entire page blank.

build.py must write the data directly into the HTML like this: 
// build.py generates index.html containing:
<script>
const CV_DATA = {...all cv_data.json content embedded here as a JS object...};
renderAll(CV_DATA);
</script>

How PDF works

The PDF section is a hidden <div id="pdf-page"> that becomes visible only during printing. showPDF() hides the main shell, shows the PDF div, calls window.print(), then restores both.

function showPDF(){
  document.querySelector('.shell').style.display='none';
  document.getElementById('pdf-page').style.display='block';
  window.print();
  document.querySelector('.shell').style.display='';
  document.getElementById('pdf-page').style.display='none';
}
