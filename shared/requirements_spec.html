Date Handling

Dates are loaded as Python datetime objects via gspread — convert to date objects:

def to_date(v):
    if isinstance(v, datetime): return v.date()
    if isinstance(v, date): return v

Tenure Calculation
def tenure(from_date, to_date, is_current=False):
    end = date.today() if is_current or not to_date else to_date
    months = (end.year - from_date.year) * 12 + end.month - from_date.month
    return max(months // 12, 0), max(months % 12, 0)
Critical Rules
  • Total experience = sum of individual role tenures — NOT career span min→max
  • Multi-role company tenure = sum of individual role tenures within that company — NOT date span
  • Bangkok priority — if Bangkok is in a role's locations, display it first; deduplicate locations
  • Role-level skills = union of ALL task skills for that role (distinct)
  • Task-Skills deduplication — table may have duplicate entries; use distinct joins
  • Key Skills — filter Skills where Key Skills == 'Y' for sidebar

09 GitHub Actions Workflow
name: Build CV
on:
  push:
    branches: [main]
  workflow_dispatch:  # enables manual "Run workflow" button in GitHub Actions tab

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-python@v4
        with:
          python-version: '3.11'
      - name: Install dependencies
        run: pip install -r pipeline/requirements.txt
      - name: Build CV
        env:
          GOOGLE_SERVICE_ACCOUNT_JSON: ${{ secrets.GOOGLE_SERVICE_ACCOUNT_JSON }}
          GOOGLE_SHEET_ID: ${{ secrets.GOOGLE_SHEET_ID }}
        run: python pipeline/build.py
      - name: Commit output
        run: |
          git config user.name "github-actions"
          git config user.email "actions@github.com"
          git add docs/
          git diff --staged --quiet || git commit -m "Rebuild CV [skip ci]"
          git push
Build failure sends GitHub email notification automatically — no extra setup needed.
GitHub Pages Setup

The repository must be configured to serve GitHub Pages from the docs/ folder on the main branch:

  1. Go to repository Settings → Pages
  2. Under Source, select Deploy from a branch
  3. Set branch to main and folder to /docs
  4. Save — GitHub Pages will serve docs/index.html at https://praphani.github.io/interactive-CV
The build script writes output to docs/index.html. GitHub Pages must point to the docs/ folder — not root — for this to work correctly.
Triggering a Rebuild

The workflow runs on two triggers:

  • Push to main — any code change automatically rebuilds and deploys
  • workflow_dispatch — manual button in GitHub Actions tab. Use this after updating the Google Sheet without making any code changes.
Typical data update flow: Update Google Sheet → GitHub repo → Actions tab → "Build CV" → "Run workflow" button → wait ~60 seconds → live at praphani.github.io/interactive-CV

function drawRadar(){
  const canvas=document.getElementById('radarChart');
  const inner=canvas.parentElement;
  const W=inner.clientWidth, H=inner.clientHeight;
  canvas.width=W; canvas.height=H;
  const CX=W/2, CY=H/2;
  const FONT=8, LINE_H=10, GAP=4;
  const R=Math.min(CX,CY)-(GAP+2*LINE_H+6);
  const ctx=canvas.getContext('2d');
  function angle(i){return(Math.PI*2/N)*i-Math.PI/2;}
  function polar(r,i){return{x:CX+r*Math.cos(angle(i)),y:CY+r*Math.sin(angle(i))};}
  function hexPath(r){ctx.beginPath();for(let i=0;i<N;i++){const p=polar(r,i);i===0?ctx.moveTo(p.x,p.y):ctx.lineTo(p.x,p.y);}ctx.closePath();}
  for(let ring=1;ring<=RINGS;ring++){hexPath((R/RINGS)*ring);ctx.strokeStyle=cobalt;ctx.lineWidth=0.5;ctx.globalAlpha=0.2;ctx.stroke();ctx.globalAlpha=1;}
  for(let i=0;i<N;i++){const p=polar(R,i);ctx.beginPath();ctx.moveTo(CX,CY);ctx.lineTo(p.x,p.y);ctx.strokeStyle=cobalt;ctx.lineWidth=0.75;ctx.globalAlpha=0.2;ctx.stroke();ctx.globalAlpha=1;}
  hexPath(R);ctx.strokeStyle=cobalt;ctx.lineWidth=2.5;ctx.globalAlpha=0.85;ctx.stroke();ctx.globalAlpha=1;
  ctx.beginPath();
  for(let i=0;i<N;i++){const r=(radarAxes[i].score/RADAR_MAX)*R,p=polar(r,i);i===0?ctx.moveTo(p.x,p.y):ctx.lineTo(p.x,p.y);}
  ctx.closePath();ctx.fillStyle='rgba(112,252,142,0.75)';ctx.fill();
  ctx.font=`600 ${FONT}px "Geist Mono"`;ctx.fillStyle=cobalt;ctx.globalAlpha=0.9;
  for(let i=0;i<N;i++){
    const a=angle(i),lx=CX+(R+GAP)*Math.cos(a),ly=CY+(R+GAP)*Math.sin(a);
    const lines=radarAxes[i].label,totalH=lines.length*LINE_H;
    let align=lx<CX-6?'right':lx>CX+6?'left':'center';
    let startY=i===0?ly-totalH-2:i===N/2?ly+4:ly-totalH/2;
    startY=Math.max(2,Math.min(startY,H-totalH-2));
    ctx.textAlign=align;ctx.textBaseline='top';
    lines.forEach((line,li)=>ctx.fillText(line,lx,startY+li*LINE_H));
  }
  ctx.globalAlpha=1;
}
