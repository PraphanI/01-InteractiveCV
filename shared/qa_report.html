⚠ cv_data.json missing required qr_b64 field
The spec (Section 03) defines qr_b64 as a required top-level field in cv_data.json. The field is absent from the uploaded cv_data.json.

The QR code still renders in index.html because the base64 PNG is hardcoded directly into the HTML rather than sourced from the JSON. This means the build pipeline is not generating or embedding the QR via cv_data.json as the spec intends.

Recommendation: Ensure build.py generates the qr_b64 field and outputs it into cv_data.json. The HTML should then read CV_DATA.qr_b64 rather than using a hardcoded value.
